# Five of Swords

แก่นตามต้นทาง: **ความขัดแย้งและเอาชนะ** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด388)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | ไม่อยากเสี่ยงกับคนที่เล่นเกม |
| แอบชอบ | อยากเอาชนะใจหรือเอาชนะคู่แข่ง |
| คุยกัน | ทะเลาะหรือใช้คำพูดทำร้ายกัน |
| ซับซ้อน | มีการแย่งชิงหรือเล่นเกมทางอารมณ์ |
| มีแฟน | ต่างฝ่ายต้องการเป็นผู้ชนะ |
| เลิกกัน | ยังมีทิฐิหรืออยากเอาชนะกันแม้เลิกแล้ว |
