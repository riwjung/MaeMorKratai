# Nine of Swords

แก่นตามต้นทาง: **ความกังวลและคิดมาก** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด404)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | กังวลว่าจะไม่มีใครรัก |
| แอบชอบ | คิดถึงคนที่ชอบจนเครียด |
| คุยกัน | กังวลว่าอีกฝ่ายจะหายไป |
| ซับซ้อน | เครียดกับความลับหรือสถานการณ์ไม่ชัดเจน |
| มีแฟน | กลัวเสียความสัมพันธ์และคิดมาก |
| เลิกกัน | เสียใจ นอนไม่หลับ หรือโทษตัวเองหลังเลิกกัน |
