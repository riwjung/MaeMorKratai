# Judgement

แก่นตามต้นทาง: **การตื่นรู้และโอกาสครั้งที่สอง** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด204)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | ทบทวนบทเรียนรักเก่า |
| แอบชอบ | ตัดสินใจเผยความรู้สึก |
| คุยกัน | ต้องตัดสินใจว่าจะไปต่อหรือไม่ |
| ซับซ้อน | ถึงเวลาตัดสินใจและรับผลจากการเลือก |
| มีแฟน | เคลียร์ปัญหาและเริ่มต้นใหม่ |
| เลิกกัน | มีโอกาสกลับมาคุยหรือคืนดี แต่ต้องเปลี่ยนจากเดิม |

ตารางถอดจากแหล่งเดียวกันทุกช่อง ([[tarot-love-chat-source-2026-10-15]])

**ดูจากภาพ:** เทวดาเป่าแตรจากท้องฟ้า ขณะที่ผู้คนลุกขึ้นจากโลงและหันไปหาเสียงเรียก ([[tarot-love-chat-source-2026-10-15]], message28)

**ทำไมจึงแปลแบบนี้?:** เสียงแตรสื่อถึงการเรียกให้ตื่นขึ้น ผู้คนที่ลุกจากโลงสื่อถึงการเปลี่ยนผ่านจากสภาพเดิมไปสู่การรับรู้ใหม่ ไพ่จึงเกี่ยวข้องกับการทบทวนสิ่งที่ผ่านมาและการตัดสินใจว่าจะใช้ชีวิตต่ออย่างไร ([[tarot-love-chat-source-2026-10-15]], message28)

**หลักจำ:** Judgement คือการตื่นขึ้นมาเห็นความจริงและตัดสินใจ ไม่ได้แปลว่าแฟนเก่าจะกลับมาเสมอไป ([[tarot-love-chat-source-2026-10-15]], message28)
