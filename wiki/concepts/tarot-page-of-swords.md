# Page of Swords

แก่นตามต้นทาง: **การสังเกตและอยากรู้** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด412)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | สนใจคนใหม่และคอยสังเกต |
| แอบชอบ | แอบดูหรือสืบข่าวคนที่ชอบ |
| คุยกัน | ถามคำถามและสังเกตท่าที |
| ซับซ้อน | ไม่ไว้ใจกันหรือจับตาดูสถานการณ์ |
| มีแฟน | ต้องสื่อสารให้ตรงประเด็น |
| เลิกกัน | อาจติดตามข่าวคราวของแฟนเก่า แต่ไม่ได้แปลว่ายังรักเสมอไป |
