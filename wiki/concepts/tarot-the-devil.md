# The Devil

แก่นตามต้นทาง: **แรงปรารถนาและพันธนาการ** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด159)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | หลงเสน่ห์ใครบางคน |
| แอบชอบ | แรงดึงดูดทางกายสูง |
| คุยกัน | ความสัมพันธ์เน้นความต้องการหรือหึงหวง |
| ซับซ้อน | ผูกพันแบบตัดไม่ขาด ความลับ หรือความสัมพันธ์ที่ไม่ดีต่อใจ |
| มีแฟน | หึงหวง ยึดติด หรือหลงใหลกันมาก |
| เลิกกัน | ยังตัดใจไม่ได้หรือวนกลับไปหาเพราะความผูกพัน |

ตารางถอดจากแหล่งเดียวกันทุกช่อง ([[tarot-love-chat-source-2026-10-15]])

**ดูจากภาพ:** มีปีศาจอยู่เหนือชายหญิงสองคน ซึ่งมีโซ่อยู่บริเวณคอ ([[tarot-love-chat-source-2026-10-15]], message28)

**ทำไมจึงแปลแบบนี้?:** โซ่สื่อถึงพันธนาการ ขณะที่ตัวละครมีความเชื่อมโยงกับปีศาจ จึงใช้แทนความสัมพันธ์ที่ผูกติดกับความปรารถนา ความกลัว หรือนิสัยที่ไม่เป็นประโยชน์ แม้จะรู้สึกว่าตัวเองเลือกได้ก็ตาม ([[tarot-love-chat-source-2026-10-15]], message28)

**หลักจำ:** Devil ไม่ได้แปลว่าความรักนั้นเลวร้ายเสมอไป แต่ชวนถามว่า *สิ่งที่ผูกพันเราสองคนอยู่คือความรักที่เป็นอิสระ หรือความต้องการที่ควบคุมเรา?* ([[tarot-love-chat-source-2026-10-15]], message28)
