# Page of Pentacles

แก่นตามต้นทาง: **การเริ่มต้นอย่างจริงจัง** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด481)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | มีคนเข้ามาแบบค่อยเป็นค่อยไป |
| แอบชอบ | สนใจและอยากทำความรู้จัก |
| คุยกัน | เริ่มแสดงความจริงใจผ่านการกระทำ |
| ซับซ้อน | สนใจแต่ยังพัฒนาช้า |
| มีแฟน | เริ่มวางแผนอนาคตเล็ก ๆ ร่วมกัน |
| เลิกกัน | อาจกลับมาพูดคุยเพื่อเริ่มต้นใหม่อย่างระมัดระวัง |
