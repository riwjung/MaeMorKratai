# Justice

แก่นตามต้นทาง: **ความจริงและความยุติธรรม** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด123)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | เลือกคู่ด้วยเหตุผล |
| แอบชอบ | ชั่งใจว่าจะเข้าหาหรือไม่ |
| คุยกัน | ต้องการความชัดเจน |
| ซับซ้อน | ต้องรับผิดชอบต่อการเลือกและพูดความจริง |
| มีแฟน | แบ่งหน้าที่อย่างเป็นธรรม |
| เลิกกัน | คุยเพื่อหาข้อสรุปหรือปิดความสัมพันธ์ |

ตารางถอดจากแหล่งเดียวกันทุกช่อง ([[tarot-love-chat-source-2026-10-15]])

**ดูจากภาพ:** บุคคลนั่งบนบัลลังก์ ถือดาบในมือหนึ่งและตาชั่งอีกมือหนึ่ง ([[tarot-love-chat-source-2026-10-15]], message28)

**ทำไมจึงแปลแบบนี้?:** ดาบเชื่อมโยงกับการตัดสินใจอย่างชัดเจน ส่วนตาชั่งสื่อถึงการชั่งน้ำหนักข้อเท็จจริงและความเป็นธรรม จึงใช้ตีความเรื่องข้อตกลง ความรับผิดชอบ และการต้องเผชิญหน้ากับความจริง ([[tarot-love-chat-source-2026-10-15]], message28)

**หลักจำ:** Justice ถามว่า *สิ่งที่เกิดขึ้นมีความจริงและความรับผิดชอบอยู่ตรงไหน* ไม่ได้แปลว่าคนถามจะเป็นฝ่ายถูกเสมอไป ([[tarot-love-chat-source-2026-10-15]], message28)
