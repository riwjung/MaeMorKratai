# Strength

แก่นตามต้นทาง: **ความอดทนและความอ่อนโยน** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด96)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | ค่อย ๆ เปิดใจ |
| แอบชอบ | อดกลั้นไม่กล้าเผยความรู้สึก |
| คุยกัน | ต้องใช้เวลาให้ความไว้ใจ |
| ซับซ้อน | ฝืนทนกับสถานการณ์ |
| มีแฟน | ประคับประคองด้วยความเข้าใจ |
| เลิกกัน | ควบคุมใจและเยียวยาตัวเอง |

ตารางถอดจากแหล่งเดียวกันทุกช่อง ([[tarot-love-chat-source-2026-10-15]])

**ดูจากภาพ:** หญิงคนหนึ่งใช้มือสัมผัสปากสิงโตอย่างสงบ มีสัญลักษณ์อินฟินิตี้อยู่เหนือศีรษะ ([[tarot-love-chat-source-2026-10-15]], message28)

**ทำไมจึงแปลแบบนี้?:** หญิงไม่ได้เอาชนะสิงโตด้วยกำลัง แต่ใช้ความสงบและความอ่อนโยน จึงสื่อถึงการจัดการอารมณ์ ความกลัว และแรงปรารถนาโดยไม่ใช้ความรุนแรง ([[tarot-love-chat-source-2026-10-15]], message28)

**หลักจำ:** Strength ไม่ได้หมายถึงการยอมทุกอย่าง แต่คือ *ความเข้มแข็งที่สามารถอ่อนโยนได้โดยไม่สูญเสียขอบเขตของตัวเอง* ([[tarot-love-chat-source-2026-10-15]], message28)
