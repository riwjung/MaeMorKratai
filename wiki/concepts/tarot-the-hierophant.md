# The Hierophant

แก่นตามต้นทาง: **ความสัมพันธ์ที่เป็นทางการ** ([[tarot-love-chat-source-2026-10-15]], message16 บรรทัด69)

ขอบเขต: ความรัก6สถานะ; ต้นทางส่วนนี้ไม่แยกไพ่กลับหัว ยังรอเจ้าของทบทวนถ้อยคำก่อนเปิดบริการจริง

| สถานะ | ความหมายตามต้นฉบับ |
|---|---|
| คนโสด | มีโอกาสพบคนที่มองหารักจริง |
| แอบชอบ | ชอบแบบให้เกียรติ |
| คุยกัน | มีโอกาสตกลงเป็นแฟน |
| ซับซ้อน | ติดกรอบ ครอบครัว หรือสถานะเดิม |
| มีแฟน | วางแผนแต่งงาน สร้างครอบครัว |
| เลิกกัน | คิดถึงความสัมพันธ์ที่เคยจริงจัง |

ตารางถอดจากแหล่งเดียวกันทุกช่อง ([[tarot-love-chat-source-2026-10-15]])

**ดูจากภาพ:** บุคคลในชุดพิธีการนั่งบนบัลลังก์ มีผู้คนอยู่เบื้องหน้าและสัญลักษณ์ทางศาสนา ([[tarot-love-chat-source-2026-10-15]], message28)

**ทำไมจึงแปลแบบนี้?:** ภาพพิธีการและผู้ติดตามเชื่อมโยงกับกฎเกณฑ์ที่คนในสังคมยอมรับ จึงนำมาอ่านเรื่องการขอคบอย่างเป็นทางการ การแต่งงาน ครอบครัว และค่านิยมที่มีผลต่อความสัมพันธ์ได้ ([[tarot-love-chat-source-2026-10-15]], message28)

**หลักจำ:** ไพ่ใบนี้เน้น *ความรักที่ต้องอยู่ร่วมกับค่านิยมและกฎเกณฑ์* ไม่ได้ยืนยันว่าจะได้แต่งงานแน่นอน ([[tarot-love-chat-source-2026-10-15]], message28)
