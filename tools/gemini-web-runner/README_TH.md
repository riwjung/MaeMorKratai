# รุ่น 1.4.0 — Pro เป็นค่าเริ่มต้น และซ่อมเฉพาะตำหนิบนภาพเดิม

อัปเดต 2026-10-17: เลือก **Pro ในเมนูโมเดลแชท** ก่อนแนบ/ส่งทุกใบ และตรวจซ้ำก่อนกดส่ง หากเมนูไม่ชัดเจน ไม่มี Pro หรือเลือกแล้วไม่เปลี่ยน จะหยุดก่อนส่ง ไม่ลดเป็น Fast และไม่กดซื้อแพ็กเกจ ผู้ใช้เลือก “ใช้โมเดลที่เลือกเอง” ได้อย่างชัดเจนเมื่อต้องการควบคุมเอง ค่าเริ่มต้นหลังรีเฟรชยังเป็น Pro

Google แยกโมเดลแชทจากตัวสร้างภาพ: Pro ในเมนูแชทอาจสร้างภาพด้วย Nano Banana 2; **Nano Banana Pro** ใช้ More → **Redo with Pro** บนผลภาพตามสิทธิ์บัญชี รุ่นนี้ไม่กด Redo เพิ่มเองและไม่อ้างว่าเลือก Pro แล้วได้ Nano Banana Pro เสมอ อ้างอิง [คู่มือ Google](https://support.google.com/gemini/answer/14286560?hl=en) ตรวจ 2026-10-17

## ซ่อม The Emperor / The Chariot ที่เจนไว้แล้ว

1. กด Reload ส่วนขยายใน `chrome://extensions/` แล้วรีเฟรชแชท ดูหัวแผง **Gemini 1.4**
2. เลือก **ซ่อมภาพเดิมที่มีตำหนิ** เลือกชื่อไพ่ และนำเข้าไฟล์เดิม เช่น `Downloads/MaeMorKratai/cards-titled/v1/the-emperor.jpg`
3. เลือกจุดแก้: The Emperor เริ่มที่ **กรอบไม่ครบ**; The Chariot เริ่มที่ **คิ้วข้างเดียว** เปลี่ยนเป็นทั้งสองหรือจุดอื่นและเขียนคำอธิบายได้
4. กด **เพิ่มใบนี้เข้าคิวซ่อม / ซ่อมอีกครั้ง** แล้วกด **เตรียมใบถัดไป** เพื่อตรวจร่าง หรือ **เริ่มอัตโนมัติ** เพื่อส่ง
5. ตรวจผลใน `Downloads/MaeMorKratai/cards-repaired/v1/` ถ้ายังไม่ผ่าน ให้เลือกไฟล์เวอร์ชันที่ต้องการเป็นฐาน ปรับจุดแก้แล้วเพิ่มเข้าคิวซ่อมอีกครั้งได้

โหมดซ่อมแนบ IMG_5392.JPG + ภาพไพ่เดิม และ ref ตัวอักษรหากเลือกไว้ แต่ไม่บังคับมี ref ตัวอักษรใหม่: รักษาชื่อ ขนาดและตำแหน่งเดิม พรอมต์สั่งซ่อมเฉพาะจุดที่เลือก รักษาฉาก สี ท่าทางและรายละเอียดนอกจุดแก้ ไม่สั่งแต่งฉากใหม่

ภาพเดิมไม่มีคิ้วทั้งสองข้างไม่ถือว่ามีตำหนิโดยอัตโนมัติ; ตัวเลือกซ่อมคิ้วใช้เมื่อเจ้าของเลือกปัญหาคิ้วข้างเดียว The Emperor จึงไม่ถูกสั่งเพิ่มคิ้วโดยค่าเริ่มต้น

## งานซ่อมซ้ำและการตรวจคุณภาพ

- คิวซ่อมแยกจากคิวไม่มีชื่อและคิวชื่อ ทำใบที่เคย completed ได้โดยไม่ล้างสถานะเดิม
- เพิ่มงานซ่อมเดิมหลังดาวน์โหลดแล้ว จะเก็บรายการ attempt เก่าใน `history` และสร้าง attempt ใหม่ ไฟล์ชื่อซ้ำใช้ Chrome uniquify ไม่ทับภาพที่ชอบ
- ดาวน์โหลดสำเร็จมี `qualityStatus: owner-review-required` ไม่ได้หมายถึงอนุมัติคุณภาพภาพ ระบบยังไม่มีตัวตรวจกรอบ/คิ้วจาก pixels อัตโนมัติ และไม่วนเจนใหม่เองเพราะอาจใช้โควตาซ้ำ
- งานที่ส่งแล้วหรือสถานะไม่แน่ชัดยังต้องใช้การกู้ใบค้าง ห้ามเพิ่ม attempt ใหม่ซ้อนเพื่อเลี่ยงการเจนซ้ำ
- ภาพนำเข้าอยู่ในหน่วยความจำแท็บ; หลังรีเฟรชให้นำเข้าภาพเดิมอีกครั้ง สถานะ/ประวัติงานอยู่ใน Chrome storage หากเปลี่ยนไฟล์หลังเข้าคิวต้องกดเพิ่มเข้าคิวอีกครั้งเพื่อยืนยันภาพใหม่
- พรอมต์สร้างใหม่ทั้ง 78 ใบเพิ่มข้อกำหนดกรอบปิดครบ 4 ด้านครอบแถบชื่อและคิ้วเป็นคู่เมื่อวาดคิ้ว ไม่อ้างว่าพรอมต์จะรับประกันผลสมบูรณ์

พรอมต์พร้อมใช้กับสองใบอยู่ `repair-prompts/the-emperor.txt` และ `repair-prompts/the-chariot.txt` หากส่งด้วยมือ ให้แนบไฟล์ภาพเดิมตรงชื่อและ IMG_5392.JPG; การเตรียมไฟล์เหล่านี้ไม่ได้สร้างภาพจริง

ตรวจสคริปต์ด้วย offline fixtures และส่วนขยาย MV3 ในโปรไฟล์ทดสอบแยก ผลอยู่ `tests/artifacts/pro-repair-check.json` และรายงานเดิม ยังไม่ทดสอบปุ่มโมเดลกับบัญชี Gemini จริง และไม่ได้ซ่อม/เขียนทับไฟล์ JPG ใน Downloads ในงานแก้สคริปต์นี้

คู่มือด้านล่างเป็นประวัติรุ่นก่อน ใช้รุ่น 1.4 และขั้นตอนด้านบนสำหรับ Pro/ซ่อมภาพ

# ตัวช่วย Gemini ไพ่แม่หมอกระต่าย รุ่น 1.3.0 — ชื่อไพ่ชุดเดียวกัน

เพิ่มชื่ออังกฤษตามชื่อไพ่เดิมครบ 78 ใบ เช่น **THE FOOL** ตามที่เจ้าของยืนยัน ใช้ตัวพิมพ์ใหญ่ สีครีม ฟอนต์ sans-serif แคบมน น้ำหนักกลาง ขนาดตัวพิมพ์ใหญ่สูง 2.4% ของความสูงภาพ จุดกึ่งกลางแนวนอน 50% และเส้นฐานที่ 92% ของความสูงภาพ ไม่ขยายชื่อสั้นหรือย่อชื่อยาว

## เริ่มใช้กับภาพที่เจนไว้แล้ว

1. ใน `chrome://extensions/` กด **Reload** ส่วนขยาย แล้วรีเฟรชแชท ดูหัวแผง **Gemini 1.3** ไม่ต้องลบส่วนขยายหรือ storage
2. เลือก **เพิ่มชื่อภาพเดิม** → เลือกชื่อไพ่ใน “จับคู่ภาพเดิมทีละใบ” → เลือกไฟล์ภาพต้นฉบับที่ดาวน์โหลดไว้ ตรวจชื่อกับภาพใน “ภาพเดิมที่นำเข้า” ให้ตรงกัน
3. สำหรับใบต้นแบบแรก ติ๊ก **ทำต้นแบบชื่อ 1 ใบ** แล้วกด **เตรียมใบถัดไป** เพื่อตรวจร่าง หรือ **เริ่มอัตโนมัติ** เพื่อส่ง โหมดต้นแบบจำกัดหนึ่งใบต่อครั้งแม้ใส่จำนวนมากกว่า 1
4. ดาวน์โหลดผลและตรวจชื่อ/ขนาด/ตำแหน่ง/ภาพเดิม ถ้าชอบแล้ว เลือกไฟล์ผลนั้นใน **ภาพชื่อเวอร์ชันแรกที่ชอบ** และกด **อนุมัติภาพนี้เป็น ref ตัวอักษร** การดาวน์โหลดสำเร็จไม่ถือว่าอนุมัติภาพโดยอัตโนมัติ
5. นำเข้าภาพเดิมใบอื่น ๆ แล้วเริ่มรอบถัดไป ระบบแนบ `IMG_5392.JPG` + `MMKT_APPROVED_TITLE_REF` + `TARGET_ORIGINAL_<card-id>` ทุกครั้ง โดยสั่งแก้เฉพาะชื่อบนภาพเป้าหมาย ไม่ใช้พรอมต์สร้างฉากใหม่

สำหรับนำเข้าหลายใบ ตั้งชื่อไฟล์ให้ตรง card id เช่น `the-fool.jpg`, `THE_MAGICIAN.jpeg`, `Three_of_Wands.jpeg`, `02-the-magician.png` (เลขนำหน้าไม่จำเป็น) ไม่เดาชื่อจากไฟล์แบบ `Gemini_Generated_Image...`; จับคู่ทีละใบได้สำหรับชื่อไฟล์เหล่านั้น หากมีชื่อไม่รู้จักหรือไพ่ซ้ำ ระบบไม่รับชุดที่นำเข้านั้นเลยเพื่อไม่จับคู่ผิด

**ภาพที่เลือกอยู่ในหน่วยความจำของแท็บเท่านั้น** หลังรีเฟรช/ปิดแท็บต้องเลือกภาพต้นฉบับและ ref ใหม่ พร้อมกดอนุมัติอีกครั้ง สถานะงานยังอยู่ใน Chrome storage; บันทึกเฉพาะ hash อ้างอิงและสถานะ ไม่เก็บ bytes ภาพใน progress JSON

## สร้างภาพใหม่ที่มีชื่อ

เลือก **สร้างภาพใหม่พร้อมชื่อ** และใช้ภาพต้นแบบตัวอักษรที่อนุมัติไว้ ระบบแนบ ref สไตล์เดิมกับ ref ตัวอักษรทุกใบและใช้ฉากเดิมครบ 78 ใบ หากยังไม่มีต้นแบบ ใช้ “ทำต้นแบบชื่อ 1 ใบ” ก่อน

ช่องข้าม 5 ใบเดิมใช้ในโหมดสร้างใหม่; โหมดเพิ่มชื่อภาพเดิมทำเฉพาะภาพที่นำเข้าและไม่ข้ามห้าใบนั้นโดยอัตโนมัติ ทั้งสองโหมดใช้คิวชื่อชุดเดียวกัน เมื่อไพ่ใดทำสำเร็จแล้วจะข้ามใบนั้นแม้สลับโหมด

## ไฟล์และคิวเดิม

- ภาพมีชื่อ: โฟลเดอร์ดาวน์โหลด Chrome `/MaeMorKratai/cards-titled/v1/`
- ภาพไม่มีชื่อเดิม: `/MaeMorKratai/cards/` คงอยู่ ไม่เขียนทับ; ชื่อซ้ำให้ Chrome เติมเลข
- เลือก **คิวเดิม / กู้ภาพไม่มีชื่อ** เพื่อใช้สถานะเดิม เช่น The Empress ที่รอบก่อนมีภาพแล้ว ห้ามเจนใหม่เพียงเพราะดาวน์โหลดค้าง
- งานชื่อมีรหัสคำขอเฉพาะ ป้องกันการกู้ภาพรุ่นไม่มีชื่อซึ่งเป็นไพ่ชื่อเดียวกันมาเป็นผลลัพธ์ผิดรุ่น
- “เตรียม” ยังไม่ส่ง; หากกดส่งเองและดาวน์โหลดเอง ให้ยืนยัน `SAVED` หลังตรวจภาพ อย่ากดเริ่มทับร่างเดิม; วิธีแก้ค้างด้านล่างยังใช้ได้
- หากไม่ชอบภาพที่ทำเสร็จแล้ว ให้แก้ด้วยมือใน Gemini แล้วใช้ผลที่ชอบเป็น ref; runner ข้ามใบที่ completed เพื่อป้องกันเจนซ้ำ ไม่ล้างคิวสำเร็จอัตโนมัติ

พรอมต์กำหนดฟอนต์และขนาดเดียวกันพร้อมภาพอ้างอิง แต่โมเดลสร้างภาพยังอาจสะกดผิด เปลี่ยนรายละเอียดภาพ หรือวาดขนาดตัวอักษรคลาดเคลื่อน ต้องตรวจภาพจริงก่อนรับเป็นชุดสำเร็จ ยังไม่มีการวัดฟอนต์หรือจัดตัวพิมพ์แบบ deterministic ในรุ่นนี้

ทดสอบด้วยหน้าเว็บจำลองและ Chrome extension จริงในโปรไฟล์ทดสอบแยก; ไม่กดเจนในบัญชีเจ้าของและยังไม่ยืนยันผลตัวอักษรจาก Gemini จริง คู่มือส่วนถัดไปเก็บประวัติรุ่นก่อน; ใช้เลขรุ่น 1.3 เป็นรุ่นปัจจุบัน

2. ที่chrome://extensions กดReloadของส่วนขยาย แล้วกลับมารีเฟรชGemini ดูหัวแผงว่าลงท้ายGemini1.1
3. กด **เลือกช่องพิมพ์** แล้วคลิกตรง **Ask Gemini** ด้านล่างของหน้าเว็บ รอข้อความ“เลือกช่องพิมพ์แล้ว”
4. ถ้าตรวจในแชทแล้วว่าไม่เคยส่งTheMagician: ตรวจให้ช่องพิมพ์และรูปแนบว่าง → กด **ยังไม่ได้ส่ง — ปลดใบค้าง** → ยืนยัน หากเคยส่งแล้วให้ใช้SAVEDเฉพาะเมื่อดาวน์โหลดภาพแล้วแทน
5. ตั้งจำนวน1ใบ แล้วกด **เริ่มอัตโนมัติ** หรือ **เตรียมใบถัดไป** หากต้องการตรวจร่างก่อน ปุ่มเตรียมยังไม่ส่ง

“ช่องไฟล์0”อาจเป็นปกติก่อนเปิดเมนู+ รุ่นนี้ลองวางภาพผ่านpaste handlerและเปิด+→Upload filesเมื่อจำเป็น ไม่ใช้API

หากกดเลือกช่องพิมพ์แล้วยังไม่สำเร็จ อย่าปลดค้าง/กดเริ่มซ้ำ ให้ดูกรอบสถานะและผลตรวจองค์ประกอบหน้า การทดสอบยังเป็นDOMจำลองหลายรูปแบบ ยังไม่ยืนยันว่าแชทบัญชีเจ้าของทำงานจริงครบแล้ว

## ติดตั้งครั้งเดียว

1. ใช้ Google Chrome บน Mac และล็อกอินบัญชีที่เปิดแชทนี้ได้
2. ดับเบิลคลิก `เปิดติดตั้ง.command` เพื่อเปิดโฟลเดอร์ตัวช่วย หน้า Extensions และแชท หาก macOS ไม่ยอมเปิด ให้เปิดหน้าและโฟลเดอร์เองตามข้อถัดไปได้ ไม่จำเป็นต้องปิดระบบความปลอดภัย
3. พิมพ์ `chrome://extensions` ในแถบที่อยู่ เปิด **Developer mode** มุมขวาบน
4. กด **Load unpacked** แล้วเลือกโฟลเดอร์ **extension** ภายในชุดนี้ ซึ่งมี `manifest.json` อยู่ข้างใน ไม่เลือกโฟลเดอร์หลักหรือZIP
5. กลับไปแชท Gemini ที่ระบุแล้วรีเฟรช จะเห็นแผง “แม่หมอกระต่าย · Gemini” มุมขวาล่าง

ขั้นตอน Load unpacked อ้างอิง [คู่มือ Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

## เริ่มใช้งาน

- ปล่อยเครื่องหมาย “ข้าม 5 ใบที่มีภาพแล้ว” ไว้ ระบบจะเริ่มที่ The Magician
- ลอง **จำนวนรอบนี้ 1 ใบ** ก่อน กด **เริ่มอัตโนมัติ** ระบบแนบภาพ → ใส่พรอมต์ → กดส่ง → รอภาพใหม่เสร็จ → รอดาวน์โหลดเสร็จ
- เมื่อรอบแรกผ่านและภาพถูกต้อง เพิ่มจำนวนเป็น5/10หรือตามที่ต้องการ กดเริ่มอีกครั้ง ระบบข้ามใบที่บันทึกแล้ว
- ถ้าอยากตรวจข้อความและภาพแนบก่อน ใช้ **เตรียมใบถัดไป** ปุ่มนี้แนบภาพและใส่ข้อความอย่างเดียว คุณกดส่งเองในGeminiได้
- **พักหลังใบนี้** รอให้ใบปัจจุบันจบ แล้วไม่ส่งใบถัดไป การเปลี่ยนแท็บไปแชทอื่นจะหยุดคิว
- เปิดแท็บแชทนี้เพียงแท็บเดียวระหว่างทำงาน และอย่าแก้ร่าง/กดส่งเองพร้อมกับรอบอัตโนมัติ
- ปรับ “เริ่มที่” ได้ หากต้องการเริ่มจากใบเฉพาะ ไม่ต้องใช้ค่าเริ่มต้นทุกครั้ง

ค่าเริ่มต้นเว้น15วินาทีหลังดาวน์โหลดแต่ละใบ เป็นการเว้นจังหวะส่ง ไม่ใช่การข้ามโควตาหรือทำให้สร้างได้เกินสิทธิ์บัญชี

## ภาพที่ดาวน์โหลด

Chrome บันทึกไว้ใต้โฟลเดอร์ดาวน์โหลดที่คุณตั้งค่าไว้: `MaeMorKratai/cards/<card-id>.<นามสกุลจริง>` เช่น `.jpg` สำหรับJPEG หรือ `.png` สำหรับPNG. ถ้ามีชื่อซ้ำChromeตั้งชื่อใหม่ ไม่ทับภาพเดิม ตรวจรายการได้ที่ `chrome://downloads` หรือกด **เปิดตำแหน่งไฟล์** ในแผง

ภาพblob:/data:ถูกอ่านเป็นbytesจากหน้าแชทและส่งให้Chromeบันทึก โดยตรวจชนิดไฟล์/ลายเซ็นข้อมูลและใช้สกุลตามจริง ไม่แปลงหรือครอปภาพ ไม่เก็บbase64ภาพในprogress. ภาพhttps:ใช้ลิงก์เดิม. ขนาดภาพขึ้นกับไฟล์ที่หน้าเว็บแสดง หากต้องการต้นฉบับความละเอียดสูงสุด ใช้ปุ่ม **Download full size** ของGeminiตามสิทธิ์บัญชี ภาพยังไม่ถูกเพิ่มเข้าสำรับเว็บแม่หมออัตโนมัติ

Google ระบุวิธีแนบภาพ สร้างภาพและดาวน์โหลดเต็มขนาดไว้ใน [คู่มือ Gemini Apps](https://support.google.com/gemini/answer/14286560?hl=en) ตัวช่วยนี้ไม่เลือกซื้อแพ็กเกจ ไม่กดอัปเกรด และไม่สั่ง Redo with Pro

## เมื่อมีใบค้างหรือโควตาหมด

ระบบเก็บสถานะในChromeเฉพาะเครื่องนี้ ไม่ส่งพรอมต์ซ้ำเมื่อรีโหลดหรือไม่แน่ใจว่าส่งแล้วหรือยัง

กด **ยืนยันใบค้าง** แล้วเลือกด้วยการพิมพ์:

- `SAVED` เมื่อคุณตรวจและดาวน์โหลดภาพใบนั้นเรียบร้อยแล้ว ระบบจะข้ามใบนั้น
- `UNSENT` เมื่อยืนยันว่าไม่เคยส่งจริง ๆ และช่องพิมพ์/ภาพแนบว่างแล้ว
- `RETRY` เมื่อเคยส่งแต่ตรวจคำตอบแล้วว่าไม่มีภาพ และโควตากลับมาแล้ว นี่เป็นการเลือกให้ลองใหม่ด้วยตัวเอง ไม่ใช่retryอัตโนมัติ
- ยกเลิกเพื่อคงสถานะเดิม

ถ้าติดขีดจำกัด ให้รอตามที่Geminiแจ้ง;ตัวช่วยหยุดคิว ไม่แก้CAPTCHAหรือเปลี่ยนบัญชีเพื่อข้ามโควตา ถ้าดาวน์โหลดอัตโนมัติไม่ได้ ให้กดดาวน์โหลดในGeminiเอง แล้วเลือกSAVED

**บันทึกสถานะ** ส่งออกJSONความคืบหน้าเพื่อเก็บไว้ในเครื่อง ปัจจุบันไม่มีปุ่มนำเข้าJSON;สถานะสำหรับทำต่ออยู่ในstorageของส่วนขยาย การลบส่วนขยาย/โปรไฟล์อาจทำให้สถานะหาย

## ขอบเขตและผลตรวจ

ทดสอบด้วยChromiumกับหน้าDOMจำลอง ไม่ได้ล็อกอินหรือกดเจนในแชทจริงของคุณ จึงต้องทดลอง1ใบจริงหลังติดตั้ง หน้าGeminiอาจเปลี่ยนโครงสร้างได้ หากหาช่องแนบไฟล์/ปุ่มส่งไม่ชัดเจน ระบบหยุดก่อนส่ง ใช้ **ตรวจองค์ประกอบหน้า** เพื่อดูจำนวนช่องที่ตรวจพบ ไม่ต้องส่งAPIkeyหรือเนื้อหาแชทส่วนตัวมา

ผลตรวจเดิมอยู่ `tests/artifacts/qa-report.json` และ `background-check.json`; รุ่น1.1.0เพิ่ม`dom-variants-check.json`สำหรับช่องไม่มีaria-label,shadowroot,ช่องfileinputที่สร้างภายหลังและการเลือกช่องเอง: แนบภาพทุกครั้ง,คิวทีละใบ,รอดาวน์โหลดเสร็จ,หยุดเมื่อquota/error,ไม่ทับร่าง,ไม่ส่งใบค้างซ้ำ,ไม่ใช้ภาพคำตอบเก่า,จำกัดแชทและกันสองแท็บทำงานซ้อน

ชุดนี้มีพรอมต์78ใบและJPGต้นฉบับ;ไม่มีcookie,tokenหรือAPIkey ใช้สิทธิ์storage/downloadsและเข้าถึงgemini.google.comเท่านั้น

## แก้พรอมต์และอัปเดต

พรอมต์ต้นฉบับอยู่ `animations/tarot-pilot/prompts-78/` สคริปต์ `build_data.py` สร้างdeck-data.jsและคัดลอกJPGจากvaultเดิมบนMacนี้ หากแก้โค้ด/ข้อมูลให้กดReloadส่วนขยายในchrome://extensions แล้วรีเฟรชแชทอีกครั้ง ไม่แก้คิวระหว่างกำลังเจน


## ถ้าขึ้น “มีใบค้าง The Magician” แล้วไม่เริ่ม

ข้อความนี้เป็นการกันส่งซ้ำ ไม่ได้หมายความว่าGeminiกำลังสร้างภาพอยู่ เลข“รอตรวจ1”คือมีหนึ่งใบที่ต้องตรวจสถานะ.

1. ดูในแชทว่ามีพรอมต์ The Magician ถูกส่งไปแล้วหรือยัง
2. ถ้ายังไม่เคยส่ง: ล้างเฉพาะร่าง/ภาพแนบที่ค้างอยู่ในช่องพิมพ์ → กดยืนยันใบค้าง → พิมพ์ UNSENT
3. กดเตรียมใบถัดไปเพื่อตรวจการแนบภาพก่อน ปุ่มนี้ยังไม่ส่ง ถ้าเห็นภาพกับข้อความครบ คุณกดส่งในGeminiเองได้
4. ถ้าต้องการใช้เริ่มอัตโนมัติหลังเตรียมทดสอบ: อย่ากดส่งเอง ให้ล้างร่าง/ภาพแนบ กดยืนยันใบค้าง→UNSENT แล้วกดเริ่มอัตโนมัติ
5. ถ้าส่งไปแล้ว: รอคำตอบ/ดาวน์โหลดก่อน แล้วใช้SAVED;อย่าใช้UNSENTกับคำขอที่ส่งแล้ว

รุ่น1.0.1แสดงขั้นตอนที่ค้างและเก็บสาเหตุแรกไว้ การกดเริ่มซ้ำจะไม่ทับสาเหตุแรก. หลังอัปเดตไฟล์ให้ไปchrome://extensions กดReloadของส่วนขยาย แล้วรีเฟรชหน้าGeminiด้วย โดยไม่ต้องลบส่วนขยายหรือล้างstorage.
