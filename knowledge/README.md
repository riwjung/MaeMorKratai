# คลังเนื้อหาสำหรับเว็บแม่หมอกระต่าย

อัปเดต 2026-11-05: เจ้าของแจ้งว่าแฟนตรวจความหมายไพ่รายวันจาก [แชทนี้](https://chatgpt.com/share/6ad48c4f-7994-83ec-a782-621e623e23c6) แล้วและให้ใช้หน้าแรก. คัดข้อความ `daily/cards.v1.json` ทั้ง 78 ใบไป `web/tarot/lib/daily-cards.json` โดยไม่แต่งเติม; หน้าแรกใช้แล้ว. ชุดอ้างอิงหมวดอื่นและ style guide ยังคงเป็นร่างแยกต่างหาก.

## ส่วนที่เตรียมไว้

- `sources/wiki-chat-index.json` — ดัชนี 11 แชท พร้อม URL, ข้อความ user/assistant, ขอบเขต และต้นทางใน raw
- `daily/cards.v1.json` — ข้อความไพ่รายวัน 78 ใบตามแหล่งเดิม แยก `daily_single` / `today`; ทุกใบมีต้นทางระดับข้อความ
- `daily/style.v1.json` — ข้อเสนอรูปแบบการตอบ อิง The Fool ที่ผู้ใช้ส่งในแชท และคำสั่งเรื่องโทนอบอุ่น/โครงสร้าง; ยังไม่ใช่กฎที่เจ้าของอนุมัติครบทั้งหมด
- `daily/review-checklist.json` — ช่องที่ขาดและจุดตัดสินใจ รวมสถานะรักซับซ้อนของ Major 22 ใบ
- `daily/validation.json` — ผลตรวจโครงสร้างและที่มาของข้อมูล ไม่ใช่การรับรองความแม่นยำคำทำนาย

หลักฐานฉบับเต็มอยู่ใน `raw/2026-10-20-maemorkratai-wiki-chats.json` เฉพาะข้อความ user/assistant ที่แสดงบนหน้าแชร์ 108 ข้อความ ไม่เก็บข้อความระบบ/เครื่องมือ/analysis/ข้อความซ่อน. raw เก็บในเครื่องตามกติกาโครงการ; ไม่เพิ่มข้อยกเว้น Git เพื่อเผยแพร่ต้นฉบับ

บทวิเคราะห์: `wiki/analyses/daily-tarot-voice-and-knowledge-plan.md`

## ขอบเขตการใช้

1. หน้าแรกไพ่ประจำวันเลือกข้อมูล `daily_single` ตาม `card_id` และสถานะความรัก ใช้ข้อความชุดนี้โดยตรงหลังทบทวน ไม่จำเป็นต้องให้ AI เขียนใหม่ทุกครั้ง
2. ความหมายเชิงหมวดในอีก 10 แชทเป็น `general_reference` ใช้ช่วยค้นคว้า/เรียบเรียงฉบับใหม่เมื่อมีคำสั่ง ไม่ใช้เติมช่องรายวันที่หายอัตโนมัติ
3. หน้า 3 ใบและข้อเสนอ 3+1 ใบต้องมีความหมายตามคำถาม ตำแหน่ง และไพ่ประกอบแยกต่างหาก การย่อคำอ่านหลายใบไม่ถือว่าได้คำอ่านรายวัน
4. `approved_for_web` ใน JSON ต้นทางยังเป็น `false` ตาม snapshot 2026-10-20; คำสั่งอนุมัติให้ใช้หน้าแรกวันที่ 2026-11-05 บันทึกไว้ใน README นี้และ log แทนการเขียนทับ provenance เดิม. ช่องที่ไม่มีต้นทางแสดงว่าไม่พร้อม ไม่หยิบข้อความจากอีกโหมดมาแทน
5. `null` ในความรักหมายถึงไม่มีเนื้อหาจากต้นทาง ไม่ใช่คำอ่านว่างที่ระบบอนุญาตให้เดา. `ex_partner` เก็บชื่อเดิม “คนรักเก่า”; ยังไม่ map เป็น “เลิกกัน” โดยอัตโนมัติ
6. ต้นฉบับ The Fool เป็นข้อความที่ user ส่งมา; อีก 77 ใบเป็น assistant draft ในแชท. เจ้าของแจ้งในวันที่ 2026-11-05 ว่าแฟนตรวจความหมายแล้วและอนุญาตให้ใช้หน้าแรก; การอนุมัตินี้ไม่ครอบคลุมหน้า 3 ใบ/การตอบ AI หรือช่องที่ยังเป็น null
