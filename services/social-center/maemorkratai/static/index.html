1. เตรียมบัญชี Meta

  1. เปิด Meta for Developers สร้าง App สำหรับแม่หมอกระต่าย และเพิ่มบัญชีเจ้าของเป็นผู้ดูแล/ผู้ทดสอบตามข้อกำหนดที่ Meta แสดง
  2. ตรวจสิทธิ์เพจว่าดู Insights ได้ และตรวจ IG ว่าเป็น Business/Creator เชื่อมกับเพจนี้
  3. เปิด Graph API Explorer เลือก App และ API version ที่ใช้งานอยู่ สร้าง User Access Token
  4. สิทธิ์เริ่มต้นสำหรับตรวจ: pages_show_list, pages_read_engagement, read_insights, instagram_basic, instagram_manage_insights ส่วนคอมเมนต์ให้ตรวจ instagram_manage_comments / pages_read_user_content ตาม endpoint และสิทธิ์บัญชีจริง
  5. วาง token ในช่องบนหน้านี้เท่านั้น ระบบเก็บใน macOS Keychain ไม่ต้องส่งผ่านแชต

ถ้า Meta ขอ Advanced Access, App Review หรือยืนยันธุรกิจ ให้ทำตามเงื่อนไขของแอปนั้น ระหว่างรอใช้ CSV ได้
